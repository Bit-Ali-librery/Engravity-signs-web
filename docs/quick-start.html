Tu primer letrero en Engravity

Esta guía te lleva desde cero hasta tener un letrero ADA validado y un archivo G-Code listo para producir. No necesitas experiencia previa con software vectorial — solo seguir los pasos.

Antes de empezar: Asegúrate de tener una cuenta en Engravity. Puedes crear una gratis desde el botón "Empieza Gratis" arriba o en la página de precios.

1. Instalación

Engravity está disponible para Windows, macOS y Linux. Descarga el instalador desde la página de descargas; detectaremos automáticamente tu sistema operativo.

  • Windows 10/11: instalador .exe firmado · ~85 MB
  • macOS (Apple Silicon e Intel): .dmg universal · ~92 MB
  • Linux: .AppImage portátil · ~78 MB

Una vez instalado, abre la aplicación e inicia sesión con la cuenta que creaste. La primera apertura puede tardar unos segundos mientras se descarga el motor de IA.

2. Tu primer proyecto

Crea un proyecto nuevo desde Archivo → Nuevo proyecto. Se te pedirá:

  1. Tipo de letrero: elige entre interior, exterior, ADA o personalizado.
  2. Material principal: acrílico, aluminio, MDF, espuma PVC u otro.
  3. Dimensiones: en pulgadas o milímetros.

Engravity precarga automáticamente el lienzo con guías de seguridad ADA si elegiste ese tipo, así no tienes que recordar las distancias mínimas a los bordes.

3. Herramientas vectoriales

Si vienes de Illustrator o CorelDRAW, las herramientas te van a resultar familiares. Las más usadas:

  • Pen tool (P): dibuja curvas Bézier con control completo.
  • Pathfinder (Shift+M): operaciones booleanas (unión, sustracción, intersección).
  • Texto vectorizado (T): tipografía que se convierte directamente en path para corte.
  • Mesh y warp: deformaciones avanzadas para letreros con curvatura.
Atajo útil: Mantén Espacio presionado para mover el lienzo sin cambiar de herramienta.

4. IA generativa en canvas

Si necesitas generar formas o vectores rápido, abre el panel de IA con Cmd/Ctrl + I y describe lo que quieres:

/crear letrero "Restroom"
material: aluminio cepillado
braille: UEB Grado 2
icono: figura ADA estándar

La IA genera el diseño base directamente sobre el canvas. Puedes editarlo después como cualquier otro vector.

5. Importar archivos existentes

Engravity importa nativamente .ai, .dxf, .svg y .cdr sin perder capas, gradientes ni texto editable. Arrastra el archivo al lienzo o usa Archivo → Importar.

6. Validación ADA

Cuando tu diseño esté listo, ejecuta el validador desde Herramientas → Validar ADA 703. Engravity revisa:

  • Altura de caracteres (mínimo 5/8" para letreros táctiles).
  • Contraste de color con el fondo (≥70%).
  • Espaciado entre letras y líneas.
  • Calidad del Braille UEB Grado 2.
  • Distancias a bordes y esquinas.

Si hay errores, el validador te muestra exactamente qué corregir y dónde. Cuando todo está verde, puedes exportar el reporte de cumplimiento en PDF.

7. Exportar G-Code

Con el diseño validado, abre Archivo → Exportar → G-Code. Selecciona:

  1. Perfil de máquina (Mach3, GRBL, LinuxCNC, etc.).
  2. Operaciones a realizar: Engrave, Cut, Pocket, V-Carve.
  3. Profundidad y velocidad de avance.

Engravity genera un archivo .nc limpio y listo para enviar a tu CNC. Si tienes el plan Industrial, también puedes ver la simulación 3D del corte antes de mandarlo a producción.
