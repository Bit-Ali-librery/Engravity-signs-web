Your first sign in Engravity

This guide takes you from zero to a validated ADA sign and a G-Code file ready to produce. No prior experience with vector software required — just follow the steps.

Before you start: make sure you have an Engravity account. You can create one for free from the "Start Free" button at the top, or on the pricing page.

1. Installation

Engravity is available for Windows, macOS, and Linux. Download the installer from the downloads page; we'll auto-detect your operating system.

  • Windows 10/11: signed .exe installer · ~85 MB
  • macOS (Apple Silicon and Intel): universal .dmg · ~92 MB
  • Linux: portable .AppImage · ~78 MB

Once installed, open the app and sign in with the account you created. The first launch can take a few seconds while the AI engine downloads.

2. Your first project

Create a new project from File → New project. You'll be asked for:

  1. Sign type: choose between interior, exterior, ADA, or custom.
  2. Primary material: acrylic, aluminum, MDF, PVC foam, or other.
  3. Dimensions: in inches or millimeters.

If you chose ADA, Engravity preloads the canvas with ADA safety guides automatically — so you don't have to remember the minimum distances to edges.

3. Vector tools

If you come from Illustrator or CorelDRAW, the tools will feel familiar. The most used ones:

  • Pen tool (P): draw Bézier curves with full control.
  • Pathfinder (Shift+M): boolean operations (union, subtraction, intersection).
  • Vector text (T): typography that converts directly to a cuttable path.
  • Mesh and warp: advanced deformations for curved signage.
Useful shortcut: hold Space to pan the canvas without switching tools.

4. Generative AI on canvas

If you need to generate shapes or vectors fast, open the AI panel with Cmd/Ctrl + I and describe what you want:

/create sign "Restroom"
material: brushed aluminum
braille: UEB Grade 2
icon: standard ADA figure

The AI generates the base design directly on the canvas. You can edit it afterward like any other vector.

5. Import existing files

Engravity natively imports .ai, .dxf, .svg, and .cdr without losing layers, gradients, or editable text. Drag the file onto the canvas or use File → Import.

6. ADA validation

Once your design is ready, run the validator from Tools → Validate ADA 703. Engravity checks:

  • Character height (minimum 5/8" for tactile signs).
  • Color contrast against background (≥70%).
  • Letter and line spacing.
  • UEB Grade 2 Braille quality.
  • Distances to edges and corners.

If there are errors, the validator shows you exactly what to fix and where. Once everything is green, you can export the compliance report as a PDF.

7. Export G-Code

With the design validated, open File → Export → G-Code. Pick:

  1. Machine profile (Mach3, GRBL, LinuxCNC, etc.).
  2. Operations to run: Engrave, Cut, Pocket, V-Carve.
  3. Depth and feed rate.

Engravity generates a clean .nc file ready to send to your CNC. With the Industrial plan, you can also preview a 3D simulation of the cut before sending it to production.

Ready for more? Continue with the advanced CNC configuration guide or learn how to customize machine profiles.
